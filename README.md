# airplay

Windows 音频转发：捕获虚拟声卡音频，经 AirPlay 2 推送至单个 HomePod。

## 文档权威等级（用户指令）

**仅以下三份文档经用户认可**：

1. `REQUIREMENTS.zh-CN.md` — 冻结需求（禁改，提议需用户明确授权）
2. `AGENTS.md` — 工作区边界规则
3. `docs/决策记录.md` — 用户批准的决策与流程规则（以会话记录为准重建）

**其余一切文档均为 Agent 自撰**，未经用户逐条认可；其中的错误或不实要求由 Agent 负责，与用户无关。冲突时以三文档为准。
